## 1. Environment gotchas that cost time

* `uv run ...` can hang for 10+ minutes syncing dependencies. Use
  `.venv/bin/python -m pytest ...` or `uv run --frozen --no-sync ...`.
  `uv run` / `uv lock` with the local uv (0.11.32) rewrites the `revision` line
  of `uv.lock` from 5 to 3: restore it to 5 by hand before committing.
* Running `apps/autoraffkat` and `apps/podcast-magic` tests in one pytest call
  breaks (two `conftest.py`); run them separately.
* zsh aborts a command chain on an unmatched glob. Never `pkill -f` a pattern
  that matches your own shell; kill by PID.
* Always `git fetch origin main` before judging what main contains. A stale
  local `origin/main` made me misjudge a fix once.
* The GitHub MCP tools disconnect now and then; reload them with `ToolSearch`
  (`select:mcp__github__...`).
* A squashed stacked PR leaves add/add conflicts in the next one: verify the
  tree equals main plus the PR, then `git merge -s ours origin/main`.
* CodeQL flags `os.path.realpath(<request value>)`-style code on the local
  servers. Do not pass request values to filesystem calls; compare them as
  strings against a set the server wrote and use the server's own string (see
  PR #105, `AppState.written_path`, `Runner.written_path`).
* A subpackage named like a top-level package shadows it under PyInstaller
  (autoraffkat's `fcpxml/` became `finalcut/` for that reason).
* ffmpeg: `-i -` opens as the `fd` protocol, so `-protocol_whitelist pipe`
  rejects stdin; `pipe,fd` works and still blocks nested file/http references.
  Checked on ffmpeg 6.1.1 only.
* lxml's `tree.write(path)` silently truncates the path at a NUL byte.

## 4. Transcription: what exists and what is not proven

Main has (all by the owner, merged while I was away): `colab-transcribe`
`--backend colab|parakeet|orukeet` (local MLX on Apple Silicon, plain-audio
mode), and the Colab path switched from Whisper to Orukeet (NeMo, Silero VAD,
chunks of at most 20 s). Release `colab-transcribe 2026.10.26.3`.

* **Verified here:** `colab-transcribe` tests, 375 passed on `a67b6c7`,
  Linux. They are all mocked.
* **Not verified anywhere in the repo:** the changelog's "65x-85x real time"
  (Parakeet) and "~43x" (Orukeet) have no measurement record; the Colab path
  says "Not yet run on a real Colab"; the MLX Orukeet weights are expected at
  `~/.models/orukeet-mlx` (falls back to base Parakeet) and I found no MLX
  conversion on Hugging Face (the listing shows NeMo/GGUF); whether Orukeet
  supports Finnish was not confirmed by my search (25 languages claimed, based
  on Parakeet TDT 0.6B v3); the local path runs **no forced aligner**, so word
  starts are the model's own (Whisper's were a median +87 ms early, the aligner
  brought that to 28 ms); a whole file goes through one call, so memory on an
  hour-long recording is untested.
* **podcast-magic has none of this:** `apps/podcast-magic` only has mlx-whisper
  and faster-whisper backends.
* **The measuring tool exists** (PR #111, merged): `scripts/ab/transcribe_bench.py`.
  It has never been run on real audio. The owner needs to run it on a Mac:

  ```
  uv run --package colab-transcribe python scripts/ab/transcribe_bench.py \
      run jakso.wav --out ulos --backend parakeet      # run twice; first run loads the model
  uv run --package podcast-magic python scripts/ab/transcribe_bench.py \
      compare ulos/jakso.words.json --marks merkinnat.txt \
      --baseline vanha/jakso.words.json
  ```

  `merkinnat.txt` is the format of `scripts/ab/ctc_align.py`
  (`whisper_time word own_time`, headers `TAUON JALKEEN` / `SISALLA`); the
  owner's 15 hand-marked words are not in the repo. Interpret results with the
  limits the report prints itself (one speaker, few marks, no drift, no word
  ends).
