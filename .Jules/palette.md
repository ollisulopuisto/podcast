## 2026-10-31 - Visible Focus Indication & Tablist Semantics in Desktop Web GUIs
**Learning:** In desktop-like web interfaces styled with custom CSS (`background: var(--bg); border: 1px solid var(--line);`), generic browser focus rings are easily suppressed or invisible on dark themes. Adding distinct `:focus-visible` outlines matching the design system accent token (`outline: 2px solid var(--accent); outline-offset: 2px`) ensures full keyboard navigation accessibility without introducing mouse-click focus rings. Furthermore, pairing navigation bars with ARIA `role="tablist"` / `role="tab"` / `aria-selected` ensures screen readers announce tool tabs correctly.
**Action:** When adding or auditing web GUIs in this workspace, always define explicit `:focus-visible` rules on buttons and inputs using `var(--accent)`, and enforce ARIA tab semantics in tab rendering.
